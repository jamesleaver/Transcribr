TRANSCRIBR - Installation Guide
================================

The quickest route on each platform. Full detail, troubleshooting and
uninstall instructions are in README.md.


ON A MAC (Apple Silicon)
------------------------

  Download  Transcribr-<version>-arm64.pkg  from:

    https://github.com/jamesleaver/Transcribr/releases/latest

  Double-click it and follow the prompts. That is the whole install.

  The package is signed and notarised by Apple, so it opens with no
  security warnings. Everything it needs - its own Python and the
  transcription engine - is inside it, so there is nothing else to
  download and no internet connection required.


ON A MAC (Intel, or if you prefer the Terminal)
-----------------------------------------------

  No Intel package is published, because there is no Intel Mac here to
  test one on. Open Terminal (cmd+space, type "terminal") and paste:

    curl -fsSL https://raw.githubusercontent.com/jamesleaver/Transcribr/main/macos/bootstrap.sh | bash

  This raises no security warnings either - macOS only quarantines what
  a browser downloads. It builds a Python environment on your Mac, so it
  installs Homebrew and Python if they are missing (it will ask for your
  password), needs a working connection, and takes longer than the
  package.


ON WINDOWS
----------

  Download  Transcribr-<version>-Setup.exe  from the same page and run
  it. Everything is included; it installs for your user only, so Windows
  never asks for an administrator password.

  SmartScreen will warn you, because the installer is not yet signed
  with a code-signing certificate. Click "More info" -> "Run anyway".


AFTERWARDS
----------

  Launch Transcribr from Spotlight / Launchpad / Applications on a Mac,
  or the Desktop / Start Menu on Windows.

  Whisper model weights download the first time you use a given model
  (about 1.6 GB for the recommended one), so the first transcription
  needs a connection. Everything after that runs entirely on your
  computer.

An experimental tool for transcribing audio and video files on macOS
and Windows. A Whisper engine does the transcription, an optional
speaker-detection pass works out who is speaking, the result is
grouped into likely paragraphs, and a built-in review pane lets you
check speaker labels, edit text, and listen back to the source audio
before saving as Word (.docx), PDF, or plain text. Several files can
be queued and transcribed in one unattended batch. Everything runs
locally on your computer - no audio, video, or transcripts are
uploaded to the internet.
