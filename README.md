# Transcribr

**Transcripts of interviews and hearings, made on your own computer.**

## → [transcribr.fisheggs.au](https://transcribr.fisheggs.au)

Transcribr turns a recording into a transcript you can check, label and
save as a Word document — with the speakers, the timestamps and the
parts it was unsure of all in view. Everything runs on your computer;
nothing is uploaded.

**Download:** from the [website](https://transcribr.fisheggs.au/#download),
or the [latest release](https://github.com/jamesleaver/Transcribr/releases/latest)
here — macOS (Apple Silicon and Intel) and Windows. Free of charge; by
installing you accept the
[licence agreement](https://transcribr.fisheggs.au/eula.html).

This repository holds the releases and the website. Transcribr's source
code is not public.
